## Правила Claude

1. Свои ветки называю только `claude/…`. В чужие ветки (`codex/`, `fix/`, `feature/`, `golubevna/`,
   `release/`, `agent/`, `zur-…` и т.д.) не пушу и не удаляю их без явной команды владельца.
2. `AGENTS.md`, `docs/PLAN.md`, `backend/README.md`, `ops/*` — правила ChatGPT. Меняю только по прямому
   поручению владельца, точечно.
3. **Production не трогаю.** Деплой, root/su, миграции на проде, сервер — только по прямой команде владельца.
   Push в GitHub ≠ деплой.
4. С 06.10.2026 в Notion действует **GLOBAL STOP / PAUSED_BY_USER**: ChatGPT остановлен владельцем.
   Это не мешает Claude выполнять прямые поручения владельца в этом чате.
5. Инварианты проекта (из AGENTS.md, соблюдаю так же):
   - никаких реальных ПД жителей, бэкапов, секретов в публичном репозитории (repo публичный!);
   - не угадывать и не выкидывать спорные данные владельцев/участков/счётчиков — сохранять для проверки;
   - не обходить историю/валидацию прямым SQL или `QuerySet.update()`;
   - не ослаблять auth/MFA/права/CSRF ради зелёных тестов;
   - сначала sandbox, потом production.
6. Если источники расходятся — сначала установить факт, потом что-то менять.
7. **Не больше 2 попыток на одну ошибку.** Если тот же подход не сработал дважды — остановиться и сменить план
   (или спросить владельца), а не пробовать третий раз.
8. **Перенос файлов сервер ↔ windas — только `scp` командой владельца в его PowerShell** (`ssh`/`scp` из Desktop
   Commander на windas не работают). Никогда не переносить файлы через base64 в чате и не поручать перенос помощникам.
9. Помощники: Haiku — сбор и чтение, Sonnet — разбор; на сервер — только чтение. Команды владельцу — по одной,
   с указанием сервера. Перед действием — уточнить и дождаться «давай».
10. **Пишу владельцу только по-русски** — ответы, сообщения, итоги, страницы Notion, комментарии. Английский только
    в командах, путях и именах файлов.

11. **Экономлю свои лимиты через Codex.** Тяжёлое (чтение кода и архивов, тесты, обходы сайта, анализ) отдаю Codex:
    песочница, device `2ce8fd8f…` (учётка `chatgpt-remote`), `~/claude-jobs/ИМЯ/prompt.md` → `nohup ~/claude-jobs/run.sh ИМЯ [сек] &`.
    Прошу короткий итог (`answer.md`, до ~40 строк), сам читаю только его и выборочно перепроверяю 1–2 вывода.
    Не опрашиваю часто: ставлю `send_later` на 10–20 минут. Сеть у Codex выключена — клоны и `pip` готовлю сам заранее.
    Задачи по проектам раздаю по схеме владельца **6/1/1/1/1** на 10: Труд-1 — 6, Автономия — 1, Самоопределение — 1,
    Частоты — 1, остальное — 1 (Notion: PORTFOLIO DISPATCH LEDGER).
