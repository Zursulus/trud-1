# Труд-1 — сайт товарищества

Статический прототип: главная страница, новости и демонстрационная форма входа. Орджоникидзе. Рабочий домен: https://trud-1.ru. Размещён на сервере пользователя через Nginx; HTTPS и пробное продление сертификата подтверждены выводом пользователя.

## Запуск

Откройте index.html в браузере либо выполните `python3 -m http.server 8000` в папке сайта и откройте http://localhost:8000. Сборка и установка зависимостей не требуются.

## Состав

- index.html — страница сайта
- style.css — оформление
- app.js — интерфейс и демонстрационные окна
- landscape.webp — изображение

Вход демонстрационный. Авторизация, база пользователей, обмен с 1С и прием платежей не подключены. Публикация исходников сама по себе не запускает сайт на домене.


План и результаты проверки: [docs/PLAN.md](docs/PLAN.md). Изменения GitHub не устанавливаются на сервер автоматически. Вход остаётся демонстрационным, поля ввода отключены.
