# Труд-1 — сайт товарищества

Публичная главная страница СНТ «Труд-1» и отдельная закрытая рабочая база сотрудников. Орджоникидзе. Рабочий домен: https://trud-1.ru.

## Запуск

Откройте index.html в браузере либо выполните `python3 -m http.server 8000` в папке сайта и откройте http://localhost:8000. Сборка и установка зависимостей не требуются.

## Состав

- index.html — страница сайта
- style.css — оформление
- app.js — интерфейс новостей
- landscape.webp — изображение

Кнопка входа ведёт в закрытую базу сотрудников по `/admin/`. Личного кабинета жителей, обмена с 1С и приёма платежей пока нет. Публикация исходников сама по себе не обновляет сайт на домене.


Актуальный статус и порядок работ: [docs/PLAN.md](docs/PLAN.md). Изменения GitHub не устанавливаются на сервер автоматически.
