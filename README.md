# Труд-1 — сайт товарищества

Публичная главная страница ТСН «ТРУД-1»: новости, объявления и полезная информация. Орджоникидзе. Рабочий домен: https://trud-1.ru.

## Запуск

Откройте index.html в браузере либо выполните `python3 -m http.server 8000` в папке сайта и откройте http://localhost:8000. Сборка и установка зависимостей не требуются.

## Состав

- index.html — страница сайта
- style.css — оформление
- app.js — интерфейс новостей
- landscape.webp — изображение

Django-приложение, служебная админка и кабинет жителей описаны в [backend/README.md](backend/README.md). Обмен с 1С и онлайн-приём платежей не подключены. Публикация исходников сама по себе не обновляет сайт на домене.


Актуальный статус и порядок работ: [docs/PLAN.md](docs/PLAN.md). Изменения GitHub не устанавливаются на сервер автоматически.
Совместимое обновление и откат: [ops/DEPLOYMENT.md](ops/DEPLOYMENT.md).
