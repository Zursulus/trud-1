## Правила, которые действуют (см. `CLAUDE.md`)

- Общение с владельцем — только по-русски.
- Серверы — только чтение через `claude-ro`; любые изменения — командой владельцу, по одной, с указанием сервера.
- Не больше 2 попыток на одну ошибку.
- Файлы сервер ↔ компьютер владельца — только `scp` командой владельца в его PowerShell (на Windows нужен `scp -T`, если путь с шаблоном).
- Перед долгой работой ставить себе напоминание в чат: среда может перезапуститься и сама работу не продолжит.
