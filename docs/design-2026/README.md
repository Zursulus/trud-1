# Дизайн 2026 «Море и закат» — утверждён владельцем 16.10.2026

Эскизы (Design Component HTML, inline-стили): Main (публичная главная), Cabinet / CabinetPhone (кабинет жителя),
Work (рабочее место правления), Controller (ввод показаний), SiteEditor (раздел «Сайт»).
Фото в эскизах (`/_blob/...`) = файлы репозитория: закат — `ordzhonikidze-sunset.webp`, сад — `landscape.webp`.

Токены: фон #f4f7f8, текст #13222e, вторичный #506270, море #0d5c74, закат #f08a4b, олива #5d7a3a,
фиолет (голосования) #6a5aa8, тёмная панель #13222e, линии #dfe6ea. Шрифты: Unbounded (заголовки), Manrope (текст).
Иконки — единые по смыслу: вода=капля (синяя), платежи=карта (оранжевая), обращения=облачко (олива),
голосования=бюллетень с галочкой (фиолетовая), документы=лист, участок=холмы, дом=главная.

## Реализация в Django

Эскизы задают оформление; реальные данные, формы и права остаются в Django-шаблонах.
Публичная главная выпускается отдельно и этим переносом не меняется.
