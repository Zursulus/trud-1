# Второй фактор для администраторов

Второй фактор обязателен только для superuser и участников группы «Администратор ТСН» (включая прежнее имя «Администратор СНТ»). В `/admin/` и `/work/` им нужна сессия с подтверждённым OTP: без устройства открывается штатная настройка, с настроенным устройством — штатная проверка кода. Наличие устройства без проверки кода в текущей сессии доступа не даёт.

Остальные сотрудники, операторы, контролёры и жители входят по паролю в пределах своих прав, без принудительной настройки OTP. Уже настроенные устройства и вход через штатный мастер 2FA сохраняются. Подключение второго фактора для остальных добровольное.

## Первое подключение администратора

1. Открыть `https://trud-1.ru/admin/` и войти с личным логином и паролем.
2. Открыть появившуюся настройку второго фактора, выбрать «приложение-генератор кодов», отсканировать QR-код и подтвердить первый код.
3. Сразу создать резервные коды по ссылке профиля второго фактора и хранить их вне телефона. Каждый резервный код срабатывает только один раз.

Для администратора браузер не запоминается: код нужен в каждой новой сессии. Секрет генератора и резервные коды не показываются в веб-админке даже техническому администратору.

## Потерян телефон

Сначала сотрудник подтверждает личность ответственному. Технический администратор с доступом к серверу выполняет:

```bash
cd /opt/trud-1-site/backend
sudo -u trudsite /opt/trud-1-site/.venv/bin/python manage.py reset_mfa ИМЯ_ПОЛЬЗОВАТЕЛЯ --yes
```

Команда удаляет старый генератор и резервные коды, завершает все активные сессии пользователя. При следующем входе администратор заново подключает приложение и создаёт новые резервные коды; для остальных подключение добровольное. Пароль в команду и в чат не передаётся.

## Ответственность

Технический суперпользователь выдаёт сотруднику только одну штатную роль. Сброс второго фактора не является сменой роли и не создаёт новый общий доступ.

## Перед выкаткой

Проверить на сервере список активных superuser и участников обеих административных групп, наличие подтверждённого OTP и доступность приложения/резервных кодов. Данных production в репозитории нет. Действующие сессии администраторов без OTP также потребуют настройки/проверки. Миграций и удаления устройств нет; откат — возврат предыдущего кода. После выкатки проверить вход администратора и вход оператора/контролёра/жителя по паролю.
