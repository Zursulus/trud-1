## Как выполнять

Сначала владелец подключается `ssh zur@150.241.114.47`, затем выполняет `su -`.
Каждый нумерованный шаг ниже — одна Bash-команда (heredoc/функция тоже одна команда).
Команды идут по порядку в **одной root Bash-сессии**. При любой ошибке остановиться.
До шага установки ошибки означают: не продолжать, ничего не удалять и не чинить
на production. После установки ошибок команда отката приведена в конце.
Секретные env и backup остаются root-only на сервере; не пересылать их в чат/Git.
До остановки сервиса проверить доступ к root-консоли и согласовать окно обслуживания;
исключить другие deploy/backup и внешние процессы записи во время холодного снимка.

## Приёмка владельцем и ограничения

CLI-проверки не заменяют реальный вход. После успешного marker владелец вручную
проверяет на телефоне и настольном экране: главная → «Вход / Кабинет» → обычный вход;
выбор лицевого счёта без автоматического выбора первого; кабинет → обсуждения →
профиль → обратно; смена почты с текущим паролем и настоящим кодом (только при
готовом SMTP); /work/ и модерация по правам; staff MFA; контролёр создаёт заявку
